# Support

FeedKeeper is maintained as a small open-source project. The fastest way to get help is to choose the channel
that matches the problem.

| You need help with | Use |
| ------------------ | --- |
| A broken feature or unexpected score | [Bug report](https://github.com/Skynet843/feedkeeper/issues/new?template=bug_report.yml) |
| Videos no longer being detected after a YouTube update | [YouTube layout report](https://github.com/Skynet843/feedkeeper/issues/new?template=youtube_layout.yml) |
| A feature or built-in category | [Feature request](https://github.com/Skynet843/feedkeeper/issues/new?template=feature_request.yml) |
| Setup help or a general question | [GitHub Discussions](https://github.com/Skynet843/feedkeeper/discussions) |
| A security vulnerability | [Private vulnerability report](https://github.com/Skynet843/feedkeeper/security/advisories/new) |

Before reporting a bug, try reloading both the extension and the YouTube tab. Include the FeedKeeper version,
browser version, operating system, affected page, and mode. A screenshot of the bottom-left status pill is often
the most useful diagnostic.

Never post an OpenRouter API key, browser profile, cookies, or private viewing data. If a screenshot contains
personal recommendations or account details, crop or blur them first.

The project does not provide guaranteed response times. Security reports are handled according to
[SECURITY.md](SECURITY.md).
