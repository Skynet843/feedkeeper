FeedKeeper settings

Changes save automatically.

API

Stored only in this browser. Used for TypeSafe Jev calls through OpenRouter.

Categories

Each checked category is sent to Jev as a yes/no question. The description is the definition Jev uses, so make it specific.

Add your own

Channel rules

Local channel rules are applied before AI classification and do not cost anything. Allow wins if a channel is in both lists.

Classification

Combined matching asks one direct question across the selected definitions, so strong evidence split between overlapping categories is not missed.

Free title rules

Matched as whole words or phrases, ignoring case, before contacting Jev (add plurals such as "pranks" separately). Allow rules win over block rules.

Where FeedKeeper runs

Hides Shorts shelves, single Shorts in feeds and search, and the Shorts menu entry. Shorts are never scored, so this costs nothing; with it off, Shorts are shown unfiltered.

Profiles and focus sessions

Save the current direction, sensitivity and category selection. Profiles can be applied permanently here or temporarily from the popup.

Decision history

Corrections

Choosing Always show video or Always hide video under Why? also saves the video and the filter it was judged under, while history is on. Export them to test category definitions against your own corrections (pnpm eval --corrections file.json). They never leave this browser unless you export them.

Auto remove pacing

Clicking too fast can look like a bot to YouTube. Keep these conservative.

Cache

Scores are cached per video for 14 days, so each video is only paid for once.
